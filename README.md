📱 Flutter Cadastro

Projeto de uma tela de cadastro desenvolvida em Flutter e Dart durante meus estudos.

O objetivo deste projeto é praticar a criação de interfaces e aprender a trabalhar com entrada de dados no Flutter.

📸 Preview

«Em breve adicionarei uma imagem do aplicativo funcionando.»

✨ Funcionalidades

A tela possui campos para:

- 👤 Usuário
- 📧 E-mail
- 🔒 Senha
- 🔒 Confirmação de senha
- 📱 Telefone
- 🎂 Data de nascimento

Também possui uma validação básica para verificar se a senha e a confirmação são iguais.

🛠️ Tecnologias

- Flutter
- Dart
- Material Design

📚 Conceitos que pratiquei

Durante o desenvolvimento, pratiquei:

- "StatelessWidget"
- "StatefulWidget"
- "TextField"
- "TextEditingController"
- "InputDecoration"
- "SingleChildScrollView"
- "FilteringTextInputFormatter"
- "ElevatedButton"
- "SnackBar"
- Validação básica de dados
