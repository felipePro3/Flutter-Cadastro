Tela de cadastro desenvolvida em Flutter durante as aulas, utilizando TextField, controllers e formatação de entrada.

Tela de Cadastro em Flutter
Projeto desenvolvido durante as aulas de Flutter.

E-mail
Senha
Confirmação de senha
Telefone
Data de nascimento

Flutter
Dart
Material Design
Conceitos utilizados
StatelessWidget
StatefulWidget
TextField
TextEditingController
SingleChildScrollView
InputDecoration
FilteringTextInputFormatter
ElevatedButton
Status
